# OpenFold2 model requirements

BIO-006, 2026-09-20. Proposed specification; exact-release identity and scientific acceptance remain blocked pending evidence.

Provide one individually authored Lab that submits protein sequence, optional real A3M alignments and optional explicit mmCIF templates to NVIDIA's OpenFold2 service. Preserve every returned ranked model, query/residue/atom identity and native confidence field. Finite prediction is not biological time evolution. Bound claims to research structure predictions: no claim of measured accuracy, protein activity, binding, clinical suitability or universal validation follows from model confidence.

1. Preserve exact uppercase 20-standard-residue sequence and query identity. Enforce hosted schema length 1–1000; current NIM support up to 2048 does not establish hosted acceptance of that length.
2. Validate each optional MSA's query, match columns, database identity and byte digest. Do not fabricate alignments, silently truncate hits, relabel database names, or treat paired chain collections as a monomer MSA. Sequence-only inference must remain explicitly identified as lacking MSA evidence.
3. Support explicit user-provided mmCIF templates with intact source/provenance/digest. NVIDIA 2.x selects label_asym_id A and documents native sequence alignment and ≥90% identity. No locally invented correspondence or confidence is allowed. HHR and unsupported relaxation must not be submitted as current-release features. Track template provenance and possible benchmark leakage.
4. Expose all selected parameter-set outputs in native ranked order, with source atom/residue mapping and unchanged structure text. Require nonempty parseable coordinates, exact query sequence and complete N/CA/C/O per expected residue. Missing or extra residues/atoms, duplicate identities and nonfinite values must be identified or rejected; no silently synthesized atoms.
5. Treat confidence, per-residue pLDDT, PAE and pTM as distinct native quantities with field-specific units and availability. Unknown confidence definitions and missing fields remain explicit. Never substitute Boltz scores, measured structural accuracy or experimental B-factor meanings. PAE need not be symmetric or zero on the diagonal.
6. Canonical io, typed runtime ports and Lab maps_to must match. One ONCE_BEFORE_RUN network operation per run, bounded inputs/response/observation, secure environment credential, portable inline artifacts, safe request diagnostics, exact-input resume and no automatic POST replay.
7. Technical fixtures: complete public 1CRN chain A sequence and actual MSA Search A3M with 101 rows, plus the complete RCSB mmCIF for an explicitly template-conditioned technical case. Never treat the template-conditioned reconstruction or this old PDB entry as held-out accuracy evidence. Verify source bytes before use.
8. Independently compare native and fresh adapter runs on identical prepared inputs, selected models, MSA and templates. Capture failures, missing fields, byte hashes, structural identity, timings and version gaps. Local success is separate from managed Hub runtime and domain qualification.
9. Scientific acceptance requires an independently reviewed, leakage-controlled monomer panel with lengths/template availability stratified, known experimental structures, exact predictors/checkpoints/databases, appropriate lDDT/TM-score and aligned RMSD, uncertainty and justified thresholds. Thresholds are not invented from one fixture; missing benchmark design blocks implementation approval and research qualification.
10. Pin exact NVIDIA release/checkpoint/container versions and rights. The current model card/NIM target is 2.6.0 while published hosted OpenAPI is 2.1.0. Managed credentials/runtime and exact release equivalence remain unverified. Private candidate and exact public release need separate evidence and approvals.
